## 5. Phase 4 – SRS-to-User-Manual Coverage Matrix

**Coverage Status codes**

- **Doc** – implemented as the SRS describes. It will be documented after a click-through check during screenshot capture.
- **Doc+Dev** – implemented with an approved deviation from the SRS. It will be documented as built, with a deviation note (DV-xx).
- **Partial** – part is implemented. The supported part is documented and the rest is a gap (G-xx).
- **Gap** – not implemented. No instructions are written; the gap is logged in Appendix C.
- **Ext** – outside this manual: the AMC User Manual or SRS Phase 2.

**Verification:** no row is marked verified. No manual UAT results are recorded in any test guide (section 7, V-1). Verification will happen during the screenshot runs.

**Screenshot column:** Y = screenshots required, N = text only, – = none.
